# ConceptCast

ConceptCast turns complex ideas into clear educational videos using AI. An
**Agent Council** of specialized agents (Analyst → Architect → Animator)
shares state through a **Global Context Object (GCO)** to research, storyboard,
and render animations with the [Manim](https://www.manim.community/) engine,
protected by an AST-driven validation and diff-repair loop.

This repository contains the application source code. The ConceptCast project
spans two companion repositories:

| Repository | Contents |
|---|---|
| **[ConceptCast](https://github.com/jdluu/ConceptCast)** (this repo) | Application source code |
| **[ConceptCast-results](https://github.com/jdluu/ConceptCast-results)** | Benchmark manifest, per-call traces, analysis tooling, experiment plan |

## Repository Layout

| Path | Purpose |
|---|---|
| `apps/backend` | FastAPI service + Pydantic AI agent council |
| `apps/frontend` | Web UI |
| `prompts/` | Agent prompts and vendored ManimCE skill docs (adapted from [manim_skill](https://github.com/adithya-s-k/manim_skill), MIT) |
| `scripts/` | DB snapshotting, wait helpers, Infisical token |
| `apps/backend/src/scripts/benchmark_council.py` | Arm C (council) benchmark runner |
| `apps/backend/src/scripts/benchmark_monolithic.py` | Arms A/B (monolithic) benchmark runner |
| `apps/backend/src/scripts/benchmark_monolithic_v2.py` | Arms A/B v2 runner (multi-scene, must-render) |
| `apps/backend/src/scripts/run_ab_v2.py` | A/B v2 launcher (sequential, resumable) |
| `apps/backend/src/scripts/run_full_benchmark.py` | Full-run launcher: all three arms sequentially, resumable |

## Quick Start

### Prerequisites

- Node.js ≥ 22 ([nvm](https://github.com/nvm-sh/nvm) recommended; see `.nvmrc`)
- [pnpm](https://pnpm.io/) ≥ 9 (`corepack enable` works too)
- Python ≥ 3.11 with [uv](https://docs.astral.sh/uv/)
- Redis (the Makefile starts one via container runtime)
- Podman *or* Docker (sandboxed Manim rendering)
- A Manim installation locally if you want non-sandboxed rendering fallback

### 1. Clone

```bash
git clone https://github.com/jdluu/ConceptCast.git
cd ConceptCast

# Recommended: benchmark manifest + analysis tooling (sibling repo, at results/)
git clone https://github.com/jdluu/ConceptCast-results.git results
# ...or symlink an existing checkout:
ln -s /path/to/ConceptCast-results results
```

> The `results/` path is gitignored here. Either a clone or a symlink works —
> every relative path in the scripts resolves through it.

### 2. Configure secrets

Secrets are managed with [Infisical](https://infisical.com/) (project folder
`/ConceptCast/ai`). Either:

```bash
infisical login          # then run everything through: infisical run -- make dev
```

or skip Infisical entirely by copying the template and filling in local keys:

```bash
cp env.example .env      # set NANO_API_KEY and CONTEXT7_API_KEY
```

`.env` is gitignored — never commit real keys.

### 3. Install and run

```bash
make setup     # installs pnpm deps, backend venv, runs migrations
make dev       # redis + backend :8000 + worker + frontend :5173
```

Then open http://localhost:5173.

## Generating Animations

Single generation with a real model (model IDs from the validated roster in
`results/manifest/model_metadata.json`):

```bash
make generate model="openai/gpt-oss-120b" topic="the Fourier transform"
```

Logic-only smoke test without API calls:

```bash
make diagnose       # agent logic diagnostics with mocks
make generate-mock  # full E2E simulation with mock models
```

## Benchmark Runs

Benchmarks are manifest-driven: the job grid (topic × model × arm × rep) is the
single source of truth in `results/manifest/jobs.csv`, generated by
`results/manifest/generate_jobs.py` from the model roster in
`results/manifest/model_metadata.json`. The current roster is 10 models ×
5 topics × 3 arms × 2 reps = 300 jobs (see the experiment plan in
`results/plan/EXPERIMENT_PLAN.md`).

```bash
# Full benchmark — all three arms sequentially, resumable (recommended)
cd apps/backend
BENCH_TRACE_DIR=../../results/traces BENCH_RUN_ID=<run-id> BENCH_TEMPERATURE=0 \
  uv run python src/scripts/run_full_benchmark.py

# Or per-arm:
uv run python src/scripts/benchmark_council.py \
  --manifest ../../results/manifest/jobs.csv --arm C --parallelism 8
uv run python src/scripts/benchmark_monolithic_v2.py \
  --manifest ../../results/manifest/jobs.csv --arm A --trace-dir ../../results/traces
```

The runners are resumable: Arms A/B skip jobs with an existing outcome file;
Arm C skips manifest tuples already recorded as completed in the database.

After a run, snapshot the database and render the analysis:

```bash
python3 scripts/snapshot_sqlite.py data/conceptcast.db results/data/conceptcast.db
results/.venv/bin/python results/tools/figures.py   # thesis figures (300 DPI)
```

## Reproducing the 2026-09-14 results

Check out the tag `benchmark-2026-09-14` (commit `9ef77a9`) — the state the
300-job grid ran from, with stored jobs created between 03:29 and 12:03 UTC.
Every agent-behaviour path (the agent modules, the workflow steps, and the four
`prompts/*.txt` prompts) is byte-identical between that commit and `main`, so
later work does not change agent behaviour on a re-run. Commits that followed
the run but may affect the environment are listed in the tag message.

**Reserved, unpopulated schema fields.** `GlobalContext` declares four fields
that nothing writes: `key_takeaways`, `lexicon`, `decisions` and `metrics`.
They are deliberately left in place. The context injectors serialise every key,
so the Architect and Animator prompts already contain them as empty blocks —
populating them would change the prompt text and therefore the conditions the
benchmark ran under. Do not wire them up without re-running the experiments.

**Vendored corpus.** `prompts/skills/manimce/` holds 18 upstream ManimCE skill
files served by `lookup_manim_pattern`. Its contents are fixed: the loader
globs `*.md` in that directory, so adding a Markdown file there introduces a
new "topic" to the tool listing. Provenance and licence: `prompts/skills/README.md`.
