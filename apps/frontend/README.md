# ConceptCast Frontend

Vite-based React application for the ConceptCast dashboard.

## Features

- React 19
- Tailwind CSS 4
- TanStack Router & Query
- Framer Motion

## Development

Run the development server (ensure backend is running first):

```bash
pnpm dev
```

Generate API types from backend schema:

```bash
pnpm generate:api
```

## Production

Build the application:

```bash
pnpm build
```
